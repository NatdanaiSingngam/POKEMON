# ศึกยอดนักขาย

เกมกระดานโปเกมอนบนเว็บ เล่น 4 คนผ่านห้องออนไลน์ หรือเล่นคนเดียวกับบอท 3 ตัว ใช้กระดาน 3D ที่สร้างด้วย Three.js ตามแนวภาพอ้างอิง มีตัวละครเดินตามช่อง HUD ผู้เล่นสี่มุม ภาพโปเกมอนแบบพิกเซลที่สร้างในโค้ด และแอนิเมชันสำหรับทอย จับ ขาย ต่อสู้ และฟื้นทีม กติกาอยู่ใน [RULES.md](RULES.md)

## เปิดเล่น

เปิดโฟลเดอร์นี้ใน VS Code แล้วรันใน Terminal:

```powershell
npm.cmd install
npm.cmd run dev
```

เปิด `http://127.0.0.1:5173/` ในเบราว์เซอร์ แล้วเลือก **เล่นคนเดียวกับบอท** หรือ **สร้างห้องกับเพื่อน** ห้องจะมีรหัส 6 ตัวและลิงก์เชิญ เพื่อนต้องเข้าถึงเซิร์ฟเวอร์เครื่องเดียวกันได้ หากเล่นจากเครื่องอื่นในเครือข่ายเดียวกัน ให้ตั้ง `HOST=0.0.0.0` ก่อนเริ่มเซิร์ฟเวอร์ แล้วใช้ IP ของเครื่องเจ้าของห้อง กรณีเล่นผ่านอินเทอร์เน็ตต่างเครือข่ายต้องนำแอปไปโฮสต์บนเซิร์ฟเวอร์ที่รองรับ WebSocket

## เล่นกับเพื่อนผ่าน URL สาธารณะ

โปรเจกต์นี้มีเซิร์ฟเวอร์ Node.js และ WebSocket อยู่แล้ว จึงใช้ **GitHub เก็บโค้ด + Render Web Service รันเกม** ไฟล์ `render.yaml` เตรียมค่าติดตั้งไว้ครบแล้ว GitHub Pages เพียงอย่างเดียวรันห้องเกมไม่ได้

1. สร้าง repository บน GitHub แล้วอัปโหลด **ไฟล์ในโฟลเดอร์นี้** ไปที่ราก repository (`package.json` และ `render.yaml` ต้องอยู่ระดับบนสุด) เลือก public หรือ private repository ก็ได้ ไม่ต้องอัปโหลด `node_modules` หรือ `dist`
2. เข้าสู่ระบบ Render แล้วเลือก **New → Blueprint** เชื่อมกับ repository นี้ จากนั้นให้ Render สร้าง Web Service ตาม `render.yaml`
3. เมื่อหน้า Deploy แสดงว่า Live ให้เปิด URL `https://<ชื่อบริการ>.onrender.com/` ที่ Render แสดง กด **สร้างห้องกับเพื่อน** และกด **คัดลอก URL** ในหน้ารอ
4. ส่ง URL `...?room=XXXXXX` ให้เพื่อน เพื่อนเปิดลิงก์ ตั้งชื่อ และกดเข้าห้อง เมื่อครบตามต้องการ เจ้าของห้องกดเริ่มเกม ที่ว่างจะมีบอทเติมให้ครบ 4 คน

ห้องเกมเก็บอยู่ในหน่วยความจำของเซิร์ฟเวอร์ การรีเฟรชหน้าเว็บกลับเข้าห้องเดิมได้ แต่หาก Render รีสตาร์ตบริการหรือ deploy เวอร์ชันใหม่ ห้องเดิมจะหายไป แผน Free อาจใช้เวลาประมาณหนึ่งนาทีในการตื่นหลังไม่มีผู้เล่นใช้งาน

```powershell
$env:HOST='0.0.0.0'
npm.cmd run dev
```

ถ้า PowerShell ไม่บล็อก `npm` สามารถใช้ `npm` แทน `npm.cmd` ได้

## ตรวจสอบ

```powershell
npm.cmd test
npm.cmd run build
npm.cmd run smoke:production
```

`npm.cmd start` เปิดเซิร์ฟเวอร์จากไฟล์ build เมื่อกำหนด `NODE_ENV=production` เกมใช้สถานะห้องในหน่วยความจำ หากปิดเซิร์ฟเวอร์เกมที่กำลังเล่นจะหายไป ส่วนรีเฟรชหน้าเว็บขณะเซิร์ฟเวอร์ยังทำงานจะกลับเข้าห้องเดิมได้

## โครงสร้าง

- `src/game/data.js` โปเกมอน อาชีพ การ์ด ราคา และช่องกระดาน
- `src/game/engine.js` กติกาและตัวตัดสินผล
- `server/index.js` ห้องออนไลน์และบอทผ่าน WebSocket
- `src/board.js` กระดานและตัวละคร 3D
- `src/game/art.js` ภาพโปเกมอนแบบพิกเซลที่สร้างจากโค้ด
- `src/game/artwork.js`, `public/pokemon-art/` ภาพโปเกมอนสำหรับการ์ดจับและทีม
- `scripts/download-artwork.mjs` ดาวน์โหลดภาพชุดเดิมอีกครั้งด้วย `node scripts/download-artwork.mjs`
- `src/main.js`, `src/style.css`, `src/hud.css`, `src/motion.css` หน้าจอและการควบคุม

โมเดล 3D เป็นงานสร้างจากรูปทรงเรขาคณิตในโค้ด จึงไม่ต้องดาวน์โหลดไฟล์โมเดลเพิ่ม
ภาพโปเกมอน 42 ตัวใน `public/pokemon-art/` มาจาก [PokéAPI sprites](https://github.com/PokeAPI/sprites/tree/master/sprites/pokemon/other/official-artwork) และเก็บไว้ในโปรเจกต์เพื่อให้เกมแสดงภาพได้แม้ไม่ได้เชื่อมต่อแหล่งภาพภายนอก
